Identification retries 429/502/503 once against the existing saved photo.
Each attempt goes through `complete()` with SDK retries disabled, gets its own
audit row and counts toward the cap; the daily analysis limit is checked before
retrying. The provider's Retry-After is honored, otherwise the delay is 1–2 s
with jitter. Both attempts and the delay share a 45-second provider budget;
transfer, processing, safety, storage and database bookkeeping can add time.
Production `LLM_TIMEOUT_MS` was verified as 60000 in both the env file and the
running container before and after deployment.

Review found that an asynchronous quota query or late timer could consume the
remaining budget and still allow another provider request. Commit `0b7d9c1`
rechecks the five-second minimum remaining allowance after both awaits. Three
regression cases fail against `faf198d`; all 27 retry tests pass with the fix.

The independent gate passed lint, typecheck, Drizzle checks, 1,293 server tests
(three configured skips), 69 component tests, build and all 186 browser tests.
