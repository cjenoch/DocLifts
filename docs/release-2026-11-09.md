## Runtime deployment

The web runtime is `doclifts-web:pr65-bf5df84`. The separately scheduled deletion
worker also requires the lease-aware code: its configuration pins the immutable
image built from the full merge commit, not an older release's worker image.
The existing web recovery images, old worker images and prior worker configuration
were retained.

The first worker dry run refused before activation: newly checked-out source had
restrictive permissions, so uid 1000 could not read it in the builder-based worker.
Permissions were corrected on tracked public source only and the worker rebuilt.
Its dry run then found zero pending jobs; a normal scheduled-service run succeeded,
and the deletion timer was resumed. The web journal socket mount was preserved.

The safety container was neither rebuilt nor restarted. The four-second limit is
in the smoke-test source, not a change to the classifier's inference or readiness.
The original five-second upload timeout's cause remains unproven. PR #64's first
production smoke scan took 0.51 s; its web-container probe took 0.79 s.
