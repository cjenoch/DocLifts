# DocLifts first-workout acceptance — draft

Status: not executed. Record date/time, tester, phone/OS/browser, displayed release/build, and gym. For each item, record Pass, Fail or Not tested plus a short observation. Use a separate test account for synthetic entries; owner gym acceptance records only real training.

- [ ] Start: sign in and reach a quick workout or editable starter program without assistance. Record confusion, missing guidance and time to the first saved set.
- [ ] Photo and manual entry: read and acknowledge the photo notice, photograph a machine, and save a set while identification runs. Review the match; verify the recorded load, reps and notes remain unchanged. If an uncertain/failed match is encountered, verify manual logging works; otherwise mark that case Not tested.
- [ ] Views: switch among Guided, Set table, Notebook and Tap sets. Verify saved values and an unsaved draft survive switching; distinguish browser drafts from saved records.
- [ ] Controls: edit an exercise and use the rest timer. Verify the selected session/program scope is clear. Observe foreground alerts; record locked/background behavior separately, without treating it as guaranteed.
- [ ] Finish: save remaining entries, finish the workout and reopen its history. Compare machine identity, units, load basis, repetitions/duration and notes with what was entered.
- [ ] Next visit: check previous performance for the same physical machine. Where repeat recognition occurs, review/undo it and confirm saved values remain intact. Keep this pending until a real repeat visit.
- [ ] Exports: from Account, download JSON, CSV ZIP and experimental Strong-style CSV. Open each file, check the completed workout and load basis, and record omitted fields. Photo metadata is included; image files and a restore endpoint are not.

Separate checks: actual fitness-app import requires a disposable destination account and comparison of dates, kg weights, exercise mapping, timed sets, notes and totals. Do not replace a valued import. Alert-email delivery and an authorized outage/recovery drill need separate evidence.

Closeout: list failures by impact, owner and next action. Unchecked cases stay pending. This checklist does not establish capacity, recovery readiness or permission to open signup.
